# 项目技术方案与开发说明

项目采用“2D 人物＋3D 场地”的 2.5D 方案。人物、回响和怪物使用透明图片显示，但移动、碰撞和攻击都在 3D 场景中完成。开发分为角色移动、怪物生成、武器攻击、回响系统、关卡流程和胜负结算几个阶段。

主要难点是让 2D 角色在 3D 场景中看起来自然。例如角色移动时不能忽大忽小，血条和阴影要始终跟随人物，子弹要准确击中怪物，相机也不能拍到地图外面。项目通过固定相机角度统一画面大小，把血条、阴影和武器绑定到角色身上，并使用圆柱碰撞体判断受伤。

武器和怪物数量、攻击距离、出生范围等内容统一写在配置中，方便直接调整。回响系统会记录玩家上一关的位置和武器操作，下一关生成一个回响，重复玩家之前的行动。这样既保留了肉鸽的成长体验，也让每一关都能积累新的战斗力量。
