## 描述

- 当前行为或现象：角色、武器、卡牌、武器插槽配件/核心和符文背包的 Description 分散显示于不同 Tooltip 或说明入口，缺少统一的正式说明框视觉表现。
- 目标行为：上述所有 Description 展示入口复用同一羊皮纸说明框风格；面板显示对应 `DisplayName` 和 `Description`，外部背景透明、纸张与手绘边框保持原始视觉。标题文本框须与羊皮纸上部内边框保留明确的视觉安全间距，不能紧贴或压迫手绘边框。
- 适用场景：
  - 角色说明；
  - 武器说明；
  - 卡牌说明；
  - 武器插槽配件/核心说明；
  - 符文背包说明。
- 影响范围：仅 UI 表现与资产绑定；不改变稳定 ID、文案数据本身、数值、效果、元素、投放、价格、存档或战斗结算。
- 明确排除：
  - 不将文字烘焙进底图；标题与正文保持动态数据投影。
  - 不在本需求中新增或修改富文本标记语法；局部加粗/斜体由 `request/vollerei/rich-text-copy-style` 独立处理。
  - 不以全屏参考图作为运行时纹理，不在策划路线手改 C++、WBP、`.uasset` 或 `.umap`。

## 复现与验收

- 运行环境与构建类型：Windows；从 `ReEcho.uproject` 启动的 Editor / PIE 路径。
- 前置条件：程序已通过 Unreal Editor 将指定透明 PNG 导入为 UI Texture2D，并为正式 Description 展示入口接入统一说明框。
- 复现步骤：
  1. 启动新游戏，分别打开角色、武器、卡牌、配件/核心和符文背包的说明入口。
  2. Hover 或聚焦对象，观察标题和 Description 是否显示于羊皮纸说明框中。
  3. 使用短文本与长文本分别检查面板的边框、自动换行、内容安全边距及点击行为。
- 出现频率：当前为正式 UI 表现缺失需求，稳定存在。
- 验收标准：
  1. 所有列出的 Description 入口均使用统一羊皮纸说明框表现，标题为对应 `DisplayName`，正文为对应 `Description`。
  2. 背景外部透明、黑色手绘边框完整、纸张区域无意外染色；文字不烘焙到纹理中。
  3. 标题文本框拥有独立的顶部 Padding / Canvas 安全边距：标题外轮廓与羊皮纸上部内边框在 1920×1080 设计面至少保留 24px 的可见间距，且标题不与手绘边框重叠或显得紧贴。
  4. 短文案和长文案均自动换行，不裁切、不与边框重叠；面板需要随内容变高时使用 Border / 9-slice 等适配方案，不直接非等比拉伸整张手绘边框。
  5. 背景与纯展示层不拦截点击；原有卡牌、背包槽位、Tooltip 和按钮交互保持可用。
  6. 1280×720、1920×1080 和一种超宽比例下无明显越界、遮挡或重叠。
  7. 无面板或资产加载失败时安全降级为现有可读 Tooltip，不出现空白说明或崩溃。
