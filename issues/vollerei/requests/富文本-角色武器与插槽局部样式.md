## 描述

- 当前行为或现象：角色体系、武器体系和武器插槽的 `Description` 是纯文本；现有普通 `TextBlock` 只能对整段文字应用单一字体样式，文案内的加粗或斜体标记会按字面显示，无法只突出局部关键词或诗意描述。
- 目标行为：策划能在角色、武器和武器插槽配件/核心的 `Description` 中为局部片段声明加粗、斜体或两者组合；正式展示路径正确渲染对应样式，未声明样式的文字保持当前普通正文表现。
- 适用场景：角色与武器选择说明 Tooltip、键盘/手柄聚焦说明，以及商店中的武器插槽配件/核心完整说明 Tooltip。
- 影响范围：仅文字展示层；不改变角色、武器、配件的稳定 ID、属性、效果、元素、投放、价格、存档或战斗结算。
- 明确排除：
  - 不要求把伤害数字字体、未获许可字体或仅数字字库用于普通 UI。
  - 不要求在本需求中变更卡牌、商城标题、按钮或世界空间伤害数字字体。
  - 不要求解析、执行或根据文案标记改变任何玩法逻辑。

## 复现与验收

- 运行环境与构建类型：Windows；从 `ReEcho.uproject` 启动的 Editor / PIE 路径。
- 前置条件：存在包含局部强调需求的角色、武器或配件 `Description` 测试文案；使用获项目发行许可、可嵌入 Cook 包且包含对应中文字符的 UI 字体与 Bold/Italic 字重。
- 复现步骤：
  1. 在角色、武器或配件的 `Description` 输入当前普通文本控件不支持的局部加粗/斜体标记。
  2. 生成 CSV、启动新游戏并打开对应角色/武器 Tooltip 或商店配件 Tooltip。
  3. 观察标记按字面显示，或无法对局部片段应用不同字重/斜体。
- 出现频率：当前设计限制下稳定出现。
- 验收标准：
  1. 程序定义并文档化稳定、可转义的策划文案标记语法；至少支持加粗、斜体和嵌套的加粗斜体。
  2. 字符/武器选择的鼠标 Tooltip、键盘/手柄聚焦说明，以及商店配件/核心完整 Tooltip 都正确渲染局部样式。
  3. 无标记的既有 `Description` 保持原有纯文本显示；非法或未闭合标记安全降级为可读文本，不造成崩溃、空白 Tooltip 或文案丢失。
  4. 中文字形完整，自动换行、长文案、低分辨率与 1920×1080 下无裁切、重叠或点击阻塞。
  5. 所用字体具有项目目标发行方式所需授权；不复用仅限伤害数字或待授权的字体资源。
