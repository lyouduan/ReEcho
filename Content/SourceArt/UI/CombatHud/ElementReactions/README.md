# Element reaction popup source art

These five transparent PNG files are the reviewed production sources supplied for the combat element-reaction labels.

- `Burn.png` → `Reaction.Burn`
- `Vaporize.png` → `Reaction.Vaporize`
- `Growth.png` → `Reaction.Growth`
- `Conduct.png` → `Reaction.Conduct`
- `Enhance.png` → `Reaction.Enhance` (shared by both enhancement element orders)

The combined `_preview_transparent.png` contact sheet is intentionally excluded from production. Runtime textures are generated by `scripts/ue/import_element_reaction_popup_assets.py`.
