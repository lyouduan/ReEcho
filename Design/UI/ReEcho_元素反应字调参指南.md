# ReEcho 元素反应字调参指南

> 面向策划与 UI 美术。本文只说明战斗中“灼烧 / 蒸发 / 生长 / 导电 / 强化”反应字的表现参数，不涉及元素规则、伤害或触发条件。

## 1. 调参资产

在 Unreal 内容浏览器中打开：

`/Game/ReEcho/UI/CombatHud/BP_ReEchoElementReactionPopup`

进入 `Class Defaults`，展开 `Element Reaction Popup` 分类。修改后点击 `Compile`、`Save`，再进入 `Level00` 触发元素反应查看效果。

五种反应共用这一套动画参数，不能在此分别设置不同速度或大小。文字与资源映射固定为：

| 反应 | 显示图片 |
|---|---|
| Burn | 灼烧 |
| Vaporize | 蒸发 |
| Growth | 生长 |
| Conduct | 导电 |
| Enhance | 强化 |

## 2. 动画参数

| 参数 | 作用 | 调大后的结果 | 建议试调范围 |
|---|---|---|---:|
| `Display Duration` | 从出现到销毁的总时间，单位为秒 | 整体播放更慢、停留更久 | `0.5–1.2` |
| `Rise Height Cm` | 生命周期内总上浮距离 | 飘得更高 | `50–140` |
| `Fade Start Fraction` | 从生命周期的哪个比例开始渐隐 | 更晚开始渐隐；`0` 为立即开始，`0.5` 为播放一半后开始 | `0–0.6` |
| `Fade Curve Exponent` | 控制开始渐隐后的透明度曲线 | 大于 `1` 时更早、更明显地变透明；小于 `1` 时较久保持清晰、接近结尾才快速消失；`1` 为线性 | `0.5–3.0` |
| `Start Scale` | 出现瞬间的整体缩放 | 初始更大 | `0.7–1.1` |
| `End Scale` | 消失前的整体缩放 | 结尾更大 | `0.9–1.2` |

常用调整方式：

- 希望“出现后马上淡出”：降低 `Fade Start Fraction`，提高 `Fade Curve Exponent`。
- 希望“先看清，再快速消失”：提高 `Fade Start Fraction`，降低 `Fade Curve Exponent` 或缩短剩余渐隐区间。
- 希望“弹一下”更明显：让 `Start Scale` 小于 `End Scale`，同时适当缩短 `Display Duration`。
- 希望整体节奏更轻柔：提高 `Display Duration`，并降低 `Rise Height Cm`。

## 3. 布局参数

| 参数 | 作用 | 调大后的结果 | 建议试调范围 |
|---|---|---|---:|
| `Spawn Height Cm` | 反应字相对怪物 Actor 原点的初始高度 | 出现位置更高 | `70–150` |
| `World Height Cm` | 图片在世界中的显示高度；宽度自动按原图比例计算 | 整体更大 | `70–150` |
| `Translucent Sort Priority` | 半透明绘制优先级 | 更倾向绘制在其他半透明表现前面 | 一般保持现值 |

`Spawn Height Cm` 与怪物体型有关。若小怪位置合适但 Boss 偏低，应先确认是否需要程序支持按体型分别配置，不要无限提高公共值。

`Translucent Sort Priority` 仅在反应字被角色、特效或地图透明层错误遮挡时调整。它不改变世界位置，也不建议作为普通大小或前后位置参数使用。

## 4. 验收清单

在 `Level00` 分别触发五类反应并确认：

- 图片与反应名称对应正确。
- 每次反应只在主目标上方出现一个反应字；导电连锁和生长影响目标不重复弹字。
- 反应字不会遮挡倒计时、小地图等屏幕 HUD。
- 从出现到消失没有突然闪断，结尾完全透明并自动销毁。
- 普通怪与 Boss 上方的位置和尺寸均可读。
- 多只怪物同时触发时，画面密度仍可接受。

## 5. 不应在此修改的内容

- 不要在 Blueprint Event Graph 中新增元素判断或伤害逻辑。
- 不要改材质参数名称 `ReactionTexture`、`Opacity`。
- 不要通过复制多个 Blueprint 分别处理五种反应；当前映射和单次生成由程序统一保证。
- 需要更换反应字图片时，把新素材交给程序重新导入；不要直接覆盖源图后假设运行时资产会自动更新。
